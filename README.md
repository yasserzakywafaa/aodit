# aodit — AI Agent Risk Index

aodit is an AI agent evaluation platform that stress-tests models across structured 8-turn scenarios, scores them on five behavioral dimensions (Reliability, Integrity, Judgment, Resistance, Resilience), and produces a composite rating (AAA–D) with deployment verdicts.

---

## Quick Start

- **Client**: `cd web && yarn install && yarn start`
- **Server**: `cd server && yarn install && yarn start:watch`
